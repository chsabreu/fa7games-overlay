# fa7herTV overlay (endereço antigo)

O overlay agora mora no DESPONTA: **https://www.desponta.live/overlay/**
(código em `chsabreu/fa7her-tv`, arquivo `public/overlay/index.html`).

Este projeto só redireciona `fa7games-overlay.vercel.app` para o endereço novo,
mantendo `?senha=...`, para as fontes antigas do OBS continuarem funcionando.
Ao conectar ao OBS, o painel novo troca o endereço das fontes sozinho.
